# Нейробиология · Нервная система

Интерактивная викторина по биологии для 9 класса. Полноэкранный сайт для урока на мультиборде: 12 вопросов с объяснениями и две нейрокарты с перетаскиванием подписей.

## Что внутри

- **Викторина** — 12 вопросов по нервной системе, 4 варианта ответа, разбор после каждого ответа, подсчёт баллов и личный рекорд.
- **Нейрокарта «Строение нейрона»** — 5 подписей: дендриты, тело нейрона, аксон, миелиновая оболочка, синапс.
- **Нейрокарта «Рефлекторная дуга»** — 6 этапов от раздражителя до рабочего органа.
- **Управление** — мышь, сенсорный экран (тап по подписи → тап по зоне) и клавиатура: `1`–`4` — ответ, `Enter` — дальше, `F` — полный экран.
- **Полный сброс** — 5 быстрых нажатий на логотип «НЕЙРО» в левом верхнем углу.

## Локальный запуск

Открыть `index.html` в браузере или запустить локальный сервер:

```bash
python -m http.server 8000
```

Затем открыть `http://localhost:8000`.

## Технологии

Чистые HTML, CSS и JavaScript без сборки и зависимостей. Шрифты Google Fonts (Manrope, Unbounded) с системным fallback. Графика — inline SVG и canvas.

## Структура

```
index.html      — разметка экранов
styles.css      — оформление и адаптив
app.js          — вопросы, викторина, нейрокарты, фон и конфетти
favicon.svg     — иконка нейрона
```
